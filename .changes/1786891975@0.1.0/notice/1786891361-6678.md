# Initial release of `fact-tests`

**Deterministic test, simulation, fixture, and benchmark harness for Facts protocol journeys.**

- Adds the Rust workspace for scenario execution, assertions, fixture
  generation, runner logic, and the `cargo sim` CLI.
- Provides deterministic Facts SDK scenario coverage for propositions,
  revisions, multi-actor activity, synchronization, conflict repair, scale,
  fault recovery, and CLI UX validation.
- Documents the repository workflows for scenarios, fixtures, benchmark
  baselines, CI orchestration, operations contracts, determinism, and scale
  profiles.
